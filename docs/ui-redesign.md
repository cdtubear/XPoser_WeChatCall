# XPoser WeChatCall UI 重构规范

版本基线：1.2.2

范围：应用外壳、好友首页、运行日志、设置页导航与组件语言

---

## 1. 设计 Tokens

### 1.1 颜色

中性色承担 95% 的界面，强调色只用于主操作、当前导航项和成功状态。

| Token | Light | Dark | 用途 |
|---|---|---|---|
| `background` | `#F6F7F5` | `#101311` | 页面底色 |
| `surface` | `#FFFFFF` | `#181C19` | 标题栏、卡片、导航 |
| `surface_alt` | `#EEF1ED` | `#202521` | 次级面板、内嵌值框 |
| `surface_pressed` | `#E7ECE6` | `#2A312C` | 按压态 |
| `stroke` | `#DEE4DD` | `#2D352F` | 默认边框 |
| `stroke_strong` | `#CDD5CC` | `#3B463E` | 输入框/次按钮边框 |
| `divider` | `#E9EDE8` | `#262D28` | 列表分隔、导航顶线 |
| `text_primary` | `#141A17` | `#EEF2EF` | 标题、正文主信息 |
| `text_secondary` | `#4F5B55` | `#B8C2BB` | 次级信息、说明 |
| `text_hint` | `#66726C` | `#98A49C` | 辅助文字、路径 |
| `text_disabled` | `#9AA49E` | `#6E7A72` | 禁用文字 |
| `primary` | `#0B7A45` | `#5DD39E` | 唯一强调色 |
| `primary_dark` | `#065E35` | `#3FB27F` | 按压态/成功文字 |
| `primary_light` | `#E8F4ED` | `#173D2C` | 选中底、成功 banner |
| `primary_disabled` | `#B8D8C6` | `#315747` | 禁用主按钮 |
| `on_primary` | `#FFFFFF` | `#072117` | 强调色上的文字/图标 |
| `danger` | `#B42318` | `#FFB4AB` | 删除、错误 |
| `danger_light` | `#FDECEA` | `#3B1E1C` | 错误图标底 |
| `info` | `#225EA8` | `#9ACBFF` | 信息标签 |
| `warning` | `#8A5A00` | `#F2C46D` | 警告标签 |

对比度：`text_primary` / `text_secondary` / `text_hint` 在 `surface` 上均 ≥ 4.5:1；主按钮文字在 `primary` 上 ≥ 4.5:1；状态色只用于小面积语义提示。

### 1.2 字体

系统无衬线字体，中文按 Android 默认回退；不使用装饰字体。

| Token | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `Text.Display` | 28 / 34sp | Bold | 品牌级大标题（预留） |
| `Text.H1` | 22 / 28sp | Bold | 页面标题 |
| `Text.H2` | 18 / 24sp | Medium | 空状态标题、好友名 |
| `Text.Section` | 13 / 18sp | Medium | 分组标签 |
| `Text.Body` | 15 / 24sp | Regular | 正文、搜索输入 |
| `Text.BodySmall` | 13 / 20sp | Regular | 说明、辅助段落 |
| `Text.Caption` | 12 / 18sp | Regular | 路径、计数、底部信息 |
| `Text.Label` | 13 / 20sp | Medium | 按钮、导航、标签 |

正文行高 24sp / 15sp = 1.6；所有行高使用 `sp`，随系统字号缩放。

### 1.3 间距

严格 8pt 体系：`8 / 16 / 24 / 32dp`。  
页面左右边距：375dp 宽 16dp；390dp 宽 20dp；430dp 宽 24dp。  
标题栏内边距 12dp 垂直；区块间距 24dp；卡片间距 16dp；列表行内边距 16dp。

### 1.4 圆角 / 阴影 / 触控

| Token | 值 | 用途 |
|---|---|---|
| `radius_small` | 12dp | 导航选中底、内嵌面板 |
| `radius_control` | 14dp | 按钮、输入框、搜索框 |
| `radius_card` | 16dp | 卡片、列表容器 |
| `Avatar` | 圆形 | 好友头像 |
| `Elevation` | 0dp | 不用阴影分层，统一用边框/背景 |
| `touch_min` | 48dp | 所有可点击元素 |
| `button_height` | 48dp | 主/次按钮 |
| `tab_bar_height` | 64dp + 底部安全区 | 底部导航 |

按钮状态：`default / pressed / focused / disabled / loading`。  
loading 通过按钮文案“读取中”、禁用主操作和骨架屏表达，不叠加 spinner 造成视觉噪音。

### 1.5 动效

- 成功 banner：进入 200ms，退出 160ms，位移 8dp + 透明度。
- 只用于操作反馈；页面切换、列表滚动、导航切换不使用装饰动画。
- `ValueAnimator.areAnimatorsEnabled() == false` 时跳过所有动画，直接显示/隐藏。

## 2. 页面信息架构与首屏优先级

### 应用外壳

底部固定 3 项：**好友 / 日志 / 设置**。  
选中项：浅绿底 + 强调色图标/文字；未选中：次级文字色。  
设置页为独立 Activity，保持同一套底部导航；详情页返回总览，总览再退出到好友页。

### 好友首页：首屏优先级从高到低

1. 页面标题“快捷通话” + 一句任务说明（我是谁、能做什么）。
2. 右上角两个操作：`从微信导入`（次按钮）、`添加`（主按钮）。
3. 搜索框：同时匹配备注与 wxid，输入即过滤。
4. “全部好友”分组标题 + 数量。
5. 好友列表：头像、备注、wxid、`创建` 主路径、更多操作。
6. 底部开源信息（弱化，不抢主任务）。

首屏 3 秒内可完成判断：当前有多少好友、如何添加、点谁可以创建通话入口。

### 日志页

1. 页面标题切换为“运行日志”，右上角刷新/清空。
2. 日志开关卡片：开关、说明、当天文件路径。
3. 输出面板：等宽字体、可选中、自动滚到底部。
4. 空状态：没有日志时给出“产生日志的条件”，不显示空白框。

### 设置页

采用“设置总览 + 4 个分组详情”，不再使用 6 个横向分类 tab。

- 总览：运行状态、设备/系统/Root 摘要、启动/停止服务、测试连接、四个分组入口。
- 分组：连接与触发（HTTP/蓝牙 + 触发/回调）、来电与播报（联系人播报/声音/试听）、设备与诊断（保活/权限 + 诊断摘要）、关于与更新。
- 标题栏进入详情后显示 48dp 返回按钮与分组标题/副标题；总览不显示返回按钮。
- 配置页底部只保留一个 48dp“保存并应用”；总览、设备、关于页隐藏，避免全局按钮跨页常驻。
- 配置统一暂存：开关与输入框只改表单，不即时写配置；有改动时显示“有未保存改动”，保存后一次写入。
- 服务启停是操作，不是配置；测试连接与 Root 检测在卡片内联显示结果，不弹原始 JSON，也不重复 toast + 弹窗。
- 原始诊断默认折叠，先显示设备/服务/Root/Hook 摘要。

## 3. 关键组件与交互状态

### 3.1 顶部标题栏

- 大标题 22sp + 12sp 辅助说明；右侧最多两个操作。
- 首页与日志页共用同一标题栏，切换 Tab 时标题/说明/操作一起切换。
- 状态栏使用浅色背景 + 深色图标；不绘制整条品牌色。

### 3.2 主/次按钮

- 主按钮：实心 `primary`，`on_primary` 文字，14sp Medium，48dp 高，14dp 圆角。
- 次按钮：白底 + 1dp `stroke_strong` 边框；按压变 `surface_pressed`；焦点 2dp 强调色描边。
- 禁用：`primary_disabled` / `surface_alt`，文字降为 `text_disabled`，同时 `setEnabled(false)`，不依赖透明度伪装。
- 图标按钮统一 48×48dp，内容描述必填。

### 3.3 搜索框

- 48dp 高，14dp 圆角，左侧搜索图标，右侧 48dp 清除热区。
- 焦点态 2dp 强调色边框；输入即过滤；清除后回到完整列表。
- 空结果使用独立空状态，不把“无结果”误判为“没有好友”。

### 3.4 好友列表

- 使用 `ListView + BaseAdapter` 虚拟化，复用 `convertView`，只绑定可见行。
- 整个列表是一块 16dp 圆角白色面板，行间 1dp 分隔线；不再一行一张卡。
- 行高最小 76dp；头像 44dp；备注 16sp Medium；wxid 12sp 等宽。
- 整行点击 = 创建通话；长按 = 编辑；右侧使用 48dp 电话图标作为明确主路径；“更多”收纳编辑/删除，减少每行按钮密度。
- 头像按 144px 解码并做 `LruCache`，避免滚动时反复读大图。

### 3.5 状态组件

| 状态 | 表现 | 触发 |
|---|---|---|
| Loading | 4 行骨架屏，保持列表容器形状；导入按钮文案变“读取中”，主/次操作 disabled | 从微信导入、首次读取 |
| Empty | 左对齐图标 + 标题 + 说明 + “从微信导入 / 手动添加” | 本地好友为空 |
| Search Empty | 搜索图标 + “没有匹配的好友” + “清除搜索” | 有好友但关键字无结果 |
| Error | 错误图标 + 原因 + “重新读取” | 导入超时/无数据 |
| Success | 浅绿 banner + 对勾 + 一句话，2.4s 后自动消失 | 导入、保存、删除、创建图标、清空日志 |

### 3.6 日志输出

- 白底卡片 + 顶部“本次输出”状态点 + 等宽 12sp 文本。
- 无日志时显示独立空状态；有日志时自动滚到底部。
- 刷新/清空为 48dp 图标按钮，清空后给出成功 banner。

### 3.7 无障碍

- 所有图标按钮有 `contentDescription`；装饰图标标记 `importantForAccessibility="no"`。
- 搜索结果、错误、成功 banner 使用语义文本，不依赖颜色单独传达状态。
- 焦点态使用 2dp 强调色描边，键盘/屏幕阅读器可见。
- 字号全部使用 `sp`；行高使用 `sp`；标题栏 `wrap_content`，大字号下不裁切。
- 触控目标 ≥ 48dp；列表行与电话图标均满足。

### 3.8 性能

- 列表使用 `ListView` 虚拟化，而非 `ScrollView + LinearLayout` 全量渲染。
- 头像降采样 + 内存缓存；不加载首屏大图。
- 骨架屏是静态占位，不做无限闪烁；减少动效设置下直接静态显示。
- 日志文本仅在日志页读取/刷新，不参与首页首屏布局。

## 4. 验收对照

- 首屏能看到：标题、任务说明、导入/添加、搜索、好友数量、列表与 48dp 电话图标。
- 设置总览：状态、设备、Root、服务启停、测试入口与四个分组入口在首屏可见；详情页有返回与分组标题。
- 375dp：左右 16dp，标题与两个操作不横向溢出；列表文字单行省略。
- 390/393dp：左右 20dp；430dp：左右 24dp。
- 所有可点击元素 ≥ 48dp；按钮具备 pressed/disabled/loading 语义。
- 加载、空、搜索空、错误、成功五种状态完整且互斥。
- 动效 160–200ms，尊重系统减少动效。
- 无 emoji 图标、无 hover、无重阴影、无渐变标题栏、无全页居中。
